# Campus-Resource-Reservation-System-Project1
Campus Resource Reservation System Project 1

##Project Description
This project is a Campus Resource Reservation System written in C++. The program allows users to view campus resources, create reservations, cancel reservations, and keep track of active reservations. The goal of this project is to practice using classes, linked lists, queues, team collaboration, and other data structures and a real useful program.
